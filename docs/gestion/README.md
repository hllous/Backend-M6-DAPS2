# Gestión ágil del proyecto

Documentación del proceso Scrum del equipo — cómo trabajamos.

## Qué hay acá

- [`definition-of-done.md`](definition-of-done.md) — criterios que una tarjeta debe cumplir para pasar a "Hecho".

## Qué NO hay acá

- **Actas de sprint planning y retrospectivas.** Las llevamos aparte, no en el repo.
- **Bitácoras individuales del challenge de la cátedra.** Son personales de cada integrante y no viven en el repo compartido.
- **Estado vivo del tablero de tareas.** Vive en Trello.

## Cadencia del proyecto

- **Sprints de 2 semanas** según cronograma de la cátedra (ver `enunciado/`).
- **Sprint Planning** el primer día de cada sprint.
- **Daily asincrónico** cada 2-3 días — cada integrante postea sus 3 puntos (experiencia / impedimentos / superación de bloqueos).
- **Sprint Review + Retro** el último día del sprint.
